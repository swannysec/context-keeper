## Release/coordination gate

Update README, current schema, platform guides, installer, copied skills/commands and changelog when behavior ships; Phase 2 updates these surfaces for fixed-root selection. Review all staged files and privacy exclusions. Compatibility claims require evidence. Provide the wrapper a stable resolution/config/schema/proposal-exclusion contract after the relevant phase passes; do not let the wrapper define a competing resolver.

Open decisions for later phases: manifest wire format; stable ID encoding and typed-relation serialization; queue behavior without a workspace; host versions and runtime verification availability. These are bounded phase decisions, not permission to introduce new requirements. Custom-root support is deferred unless the user reviews and approves it. Keep verification proportional to the task.
