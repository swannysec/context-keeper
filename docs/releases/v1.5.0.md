# Context Keeper 1.5.0

Status: published October 6, 2026, after PR #25 merged. [GitHub release](https://github.com/swannysec/context-keeper/releases/tag/v1.5.0), tag `v1.5.0`, commit `963be12f5ea8b8a1c215f520146dd3c0b8baeeb7`.

## Release notes

Context Keeper now uses consistent memory-root selection across hooks, search, configuration and workflow instructions. New projects use `.ai/memory/`. Projects with only `.claude/memory/` continue using that directory, so existing memory requires no migration. Global memory follows the same rule independently under your home directory.

If both roots exist, Context Keeper uses `.ai/memory/`, warns, and leaves legacy contents untouched. An invalid or unsafe selected root is diagnosed rather than silently switching directories. Native agent memory remains separate.

The installer offers AGENTS.md instructions with a CLAUDE.md compatibility fallback and includes memory-search. Platform packages include the root/search tools and shared libraries. A read-only root diagnostic reports the selected directory without creating it. Unsafe roots and symlinked session/handoff subdirectories are rejected before writes or cleanup.

This release adds no custom-location configuration, automatic migration, schema manifest or later-phase knowledge features. Native adapter placement is unchanged. Live Claude, Codex and other host workflows were not newly certified for this release; see [verification evidence](../vnext/verification.md).
