# Context Keeper 1.6.0

## Release notes

Context Keeper adds optional durable knowledge through its existing lightweight skills and Markdown files. Configure `knowledge_workspace` globally once; projects inherit it unless they specify another directory or explicitly disable it. Ordinary operating memory continues without a durable store.

Every proposed durable addition or change carries a citation/provenance and a verbatim source excerpt for human review. Only the reviewed claim is saved; silence and automatic project sync never approve promotion. Pending work stays in existing project session/handoff records when the store is unavailable. Those records remain excluded from default project and cross-project search; explicit session-history retrieval retains their review state.

New note/proposal templates use flat Obsidian-compatible properties, stable UUIDs, and separate lifecycle/review state. Existing human notes need no conversion. Legacy-only `.claude/memory` projects continue unchanged, and native agent memory remains separate.

Current Codex installation uses `.agents/skills`, with legacy `.codex/skills` copies retained in distributions. Codex, Copilot and Cursor native adapters include memory-config. All seven distributions include the shared workflow and templates. No manifest, migration, new parser dependency, daemon or exporter is introduced.

## Validation and limits

Existing regressions and focused search/root/packaging checks passed. Live Claude headless and Codex scratch workflows verified the exercised configuration, review, provenance and preservation behavior. Other-host verification was explicitly waived; no blanket host certification is claimed. See [implementation evidence](../vnext/lightweight-knowledge-verification.md).

Plugin QA's monorepo source rule rejects this standalone layout; applicable standalone checks pass with existing trigger warnings. This is not a formal plugin QA PASS.

Release preparation checks passed for all 22 skill names/descriptions, README references, keywords and version 1.6.0. Twelve existing native copies lack trigger arrays. All seven packages built from a tracked-source scratch copy; the shipped Claude plugin declares 1.6.0, shared workflows/templates/tools are present, and Codex's current/legacy skill copies are identical. Excluded local items were not copied into the release changes. Runtime code is unchanged by this metadata preparation; existing regression and live-host evidence remains applicable.
